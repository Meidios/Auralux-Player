# Auralux Player 1.5.82

简体中文

- 循环试听短音效时，响度历史按实际播放会话计时，使用引擎的循环结束通知标出每一圈；暂停和拖动进度不再靠播放位置差值推算。
- 波形的红色标记表示近满刻度区块（采样绝对值 ≥ 0.999）。仪表的「超满刻度采样数」只统计实时经过分析器、绝对值 > 1 的声道采样。满刻度整数 PCM 可以有红标但计数为零。
- 实时声谱图保留每个屏幕时间区间的峰值，首个分析帧可立即显示。点击 FFT 按钮选择 2K／4K 看短音效，或用较长窗口观察频率细节。
- DOT 声场默认收紧粒子的散布和直径。右键 DOT 声场可切换清晰／弥散，并记住选择；LINE 和 RAY 保持原样。

繁體中文

- 短音效循環播放時，響度歷程依播放工作階段計時，並由引擎的循環通知標記每一圈；暫停或拖曳不會造成時間軸跳動。
- 波形紅標表示接近滿刻度的區塊（取樣絕對值 ≥ 0.999）。「超滿刻度取樣數」只計算即時通過分析器且絕對值 > 1 的聲道取樣。
- 即時聲譜圖保留各螢幕時間區段的峰值，第一個分析影格即可顯示。點選 FFT 按鈕可切換窗長：2K／4K 適合短音效，較長的窗則能分辨較細的頻率差異。
- DOT 聲場預設使用較集中的粒子；在 DOT 聲場按右鍵即可切換清晰／擴散並儲存偏好。LINE 與 RAY 不變。

English

- Loudness history uses elapsed listening time and engine loop notifications. Short loops no longer rely on a large backward position jump to mark each pass. Pausing and seeking do not add the source-position jump to the timeline.
- Red waveform markers indicate near-full-scale bins (absolute sample ≥ 0.999). SAMPLE OVERS counts individual channel samples above full scale (absolute value > 1) in the active analysis stream.
- The live spectrogram retains measured peaks within each display column and draws the first analysis frame immediately. Click FFT to select a short window for transients or a longer window for frequency detail.
- DOT defaults to a tighter scatter and smaller particles. Right-click the DOT scope to choose Focused or Diffuse. The choice persists; LINE and RAY are unchanged.
