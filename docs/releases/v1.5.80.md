# Auralux Player 1.5.80

简体中文

- 可以用 Windows x64 安装包装到当前用户目录。以后覆盖安装到同一目录会保留播放列表和布局。
- 播放器底部新增「帮助」。可以立即检查更新，也可以让播放器在每次启动时检查正式版。下载前可阅读说明、稍后再说或只跳过这一版。
- 安装前会核对下载大小和 SHA-256。升级后首次打开播放器时会显示本版变化；使用帮助和更新记录断网也能查看。

繁體中文

- Windows x64 安裝精靈可為目前使用者安裝播放器。覆蓋安裝到原資料夾會保留播放清單和版面配置。
- 從播放器底部的「說明」可檢查正式版更新、設定啟動檢查，並在下載前閱讀更新說明、稍後處理或跳過單一版本。
- 安裝前會驗證檔案大小與 SHA-256。升級後首次啟動會顯示本版變更，離線也能閱讀使用說明與更新記錄。

English

- Install for the current Windows user with the x64 setup wizard. Updating in the same folder preserves playlists and layout.
- Open Help in the transport area to check for stable updates. Read the release notes before downloading, postpone the update, or skip a single version.
- Downloads are checked for size and SHA-256 before setup opens. After an upgrade, the player shows what changed. Help and release history are available offline.
