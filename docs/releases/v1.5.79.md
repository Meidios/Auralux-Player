# Auralux Player 1.5.79

简体中文

- 连续试听时，新播放流不再加启动淡入，保留打击声和短音效开头的瞬态。
- 切歌前先预缓冲；系统输出在空闲时保持设备唤醒，ASIO 切歌不再反复重启驱动。

繁體中文

- 連續試聽時，新串流不再加入啟動淡入，保留打擊聲與短音效起始的瞬態。
- 切換曲目前會先預先緩衝。系統輸出在兩次播放之間保持喚醒，ASIO 切換曲目時不再重新啟動驅動程式。

English

- New playback streams start without a fade-in, preserving the attack of short sound effects.
- The next stream is prebuffered before switching. System output stays awake between sounds, and ASIO no longer restarts the driver on each track change.
