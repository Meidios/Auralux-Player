# Auralux Player 1.5.88

简体中文

- 声场的 LINE 模式用亮度显示采样点的分布：反复经过的位置更亮，偶发轨迹快速淡出，远距离的点之间不再画长线。DOT 和 RAY 保持原样。

繁體中文

- 聲場的 LINE 模式以亮度呈現取樣點的分布：反覆經過的位置較亮，偶發軌跡快速淡出，距離較遠的點之間不再畫長線。DOT 和 RAY 維持原樣。

English

- The LINE stereo scope now shows sample density. Repeated positions brighten, isolated traces fade, and distant samples no longer draw long lines through empty space. DOT and RAY are unchanged.
