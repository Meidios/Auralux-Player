# Auralux Player 1.5.81

简体中文

- 首次打开时，播放器跟随 Windows 显示语言。支持简体中文、繁体中文和英文，其他语言使用英文。可在「帮助 → 语言」覆盖默认选择，重新打开后生效。
- 安装完成时可选择打开 Windows 默认应用设置，将需要的音频格式分配给 Auralux Player。跳过会保留现有默认播放器。

繁體中文

- 首次開啟時，播放器會跟隨 Windows 顯示語言。支援繁體中文、簡體中文與英文，其他語言使用英文。可在「說明 → 語言」變更偏好，重新開啟後生效。
- 安裝完成時可選擇開啟 Windows 預設應用程式設定，為需要的音訊格式指定 Auralux Player。略過即保留原有的預設播放器。

English

- The player follows your Windows display language on first launch. English, Simplified Chinese and Traditional Chinese are supported; other languages use English. To override this, choose Help → Language and reopen the player.
- After installation, you can open Windows Default Apps and choose which audio formats to play with Auralux Player. Skip this step to keep your current defaults.
