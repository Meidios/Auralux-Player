# Auralux Player 1.5.91

简体中文

- DOT 在实际采样位置绘制暖色粒子云。密集区域呈金色，旧粒子逐渐淡出；Focused 保留颗粒细节，Diffuse 使用更柔和的光斑。LINE 和 RAY 不变。

繁體中文

- DOT 在實際取樣位置繪製暖色粒子雲。密集區域呈金色，舊粒子逐漸淡出；Focused 保留顆粒細節，Diffuse 使用更柔和的光斑。LINE 和 RAY 不變。

English

- DOT plots a warm particle cloud at measured sample positions. Repeated hits build a golden core and older particles fade. Focused preserves individual grains; Diffuse uses a wider, softer spot. LINE and RAY are unchanged.
